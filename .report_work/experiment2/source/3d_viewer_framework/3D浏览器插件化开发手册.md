# 3D浏览器插件化开发手册

## 前置准备

### 依赖安装

pip install PyQt5 vtk pyyaml

### 目录结构

3d\_viewer\_framework/

├─ main\.py                      		\# 程序唯一启动入口，自动扫描插件、读取yaml配置

├─ plugin\_config\.yaml          	\# 插件配置文件

├─ core/

│  └─ viewer\_3d\.py              		\# 3D浏览器内核（固定底层底座，禁止修改）

├─ plugins/

│  ├─ base\_plugin\.py           		\# 插件统一抽象基类（所有插件父类）

│  ├─ plugin\_light\.py           		\# 光照功能插件示例

│  └─ plugin\_texture\.py        		\# 纹理贴图功能插件示例

└─ data/texture/               		\# 纹理素材目录

## 开发步骤

### 插件抽象基类 plugins/base\_plugin\.py（统一插件规范）

1. 定义父类 Base3DPlugin，作为所有业务插件的统一接口；
2. 强制子类定义类属性 plugin\_cls\_name（YAML配置唯一标识，自动扫描匹配关键字）；
3. 定义4个生命周期钩子函数，内核自动分发事件：
   - create\_ui\(\)：必须重写，创建插件专属UI面板，返回QWidget；
   - on\_model\_loaded\(obj\_path, actor, polydata\)：加载OBJ模型后自动触发；
   - on\_window\_resize\(\)：窗口缩放时触发；
   - on\_destroy\(\)：程序关闭时释放资源；
4. 构造函数统一接收全局上下文 viewer\_ctx，插件通过 self\.ctx 共享内核渲染、模型、UI状态。

### 内核底座 core/viewer\_3d\.py

1. 封装全局状态容器 ViewerContext，统一存储渲染器、当前模型、信息面板等共享数据；
2. 主窗口 VTKViewerCore 只保留基础能力：文件树、OBJ纯白加载、VTK渲染、坐标轴、底部信息栏；
3. 提供插件注册入口 register\_plugin\(plugin\_cls\)：
    - 实例化插件，传入全局上下文ctx；
    - 调用插件create\_ui\(\)生成面板，挂载到窗口右侧统一扩展区域；
4. 事件分发机制：
    - 加载模型完成后，遍历所有插件执行on\_model\_loaded；
    - 窗口缩放resizeEvent遍历插件执行on\_window\_resize；
    - 窗口关闭closeEvent遍历插件执行on\_destroy；
5. 布局预留右侧垂直容器，所有插件UI自动垂直堆叠，无需修改内核布局代码。

### 业务功能插件（以plugin\_light\.py / plugin\_texture\.py为例）
#### 导入依赖
插件独立导入自身使用的Qt/VTK类，不依赖内核导入，缺失布局控件会触发NameError；
示例纹理插件头部：

	import os
	from PyQt5\.QtWidgets import QWidget, QScrollArea, QGridLayout, QPushButton, QVBoxLayout
	from PyQt5\.QtCore import Qt, QSize, QTimer
	from PyQt5\.QtGui import QPixmap, QIcon
	import vtk
	from plugins\.base\_plugin import Base3DPlugin

#### 定义插件类，继承基类，配置唯一标识

	class TexturePlugin\(Base3DPlugin\):
	   	\# 关键：yaml配置填写该字符串，自动扫描匹配插件
    	plugin\_cls\_name = "texture\_mapping"
	    plugin\_name = "texture\_mapping"
	    plugin\_desc = "纹理贴图功能插件"

#### 重写生命周期钩子函数

1. 必写 create\_ui\(\)：创建插件内部所有控件、布局，最终返回面板self\.plugin\_panel；
2. 按需重写回调：
	- on\_model\_loaded：模型加载完成自动应用纹理/光照参数；
	- on\_window\_resize：窗口缩放刷新纹理缩略图尺寸；
	- on\_destroy：资源释放（无特殊资源可省略）。

#### 业务逻辑隔离，通过全局上下文交互内核
1. 所有纹理映射、光照材质调节、VTK渲染逻辑全部写在插件内部；
2. 通过self\.ctx读取/操作全局共享资源：
	- self\.ctx\.vtk\_renderer：VTK渲染场景
	- self\.ctx\.current\_actor：当前加载的模型Actor
	- self\.ctx\.info\_display：底部信息输出文本框

### 配置文件 plugin\_config\.yaml

	# 启用插件列表，注释行代表关闭该插件
	active\_plugins:
	  - texture\_mapping   \# 纹理贴图插件
	  - light\_control     \# 光照材质调节插件
	  # \- view\_toolbar      \# 顶部工具栏插件（取消注释启用）

### 统一启动入口 main\.py

1. 路径预处理：将项目根目录加入Python搜索路径，解决相对导入报错；
2. auto\_scan\_plugins\(\) 自动扫描插件机制（核心）：
	- 遍历plugins文件夹所有\.py文件，跳过base\_开头文件；
	- 使用importlib动态导入模块；
	- 筛选继承Base3DPlugin、存在plugin\_cls\_name的合法插件类；
	- 自动生成 \{plugin\_cls\_name: 插件类\} 映射字典，无需手动维护映射表；
3. 读取YAML配置容错处理：
	- 文件不存在/解析异常时，自动加载全部扫描到的插件；
4. 批量注册插件：
	- 遍历yaml配置内的插件标识，匹配映射表调用内核register\_plugin；
	- 不存在的插件标识打印警告，不中断程序运行；
5. 初始化Qt窗口、展示界面、启动事件循环。

## 自定义插件完整流程

1. 在plugins/目录新建plugin\_xxx\.py；
2. 头部导入依赖，继承Base3DPlugin，定义唯一plugin\_cls\_name；
3. 实现create\_ui\(\)，按需重写on\_model\_loaded/on\_window\_resize钩子；
4. 修改plugin\_config\.yaml，在active\_plugins中添加插件的plugin\_cls\_name；
5. 项目根目录执行python main\.py，程序自动扫描、加载、挂载插件UI。

## 运行流程

1. 终端切换到项目根目录 3d\_viewer\_framework；
2. 执行启动命令：python main\.py；
3. 控制台校验输出：打印已加载插件: xxx，无警告日志；
4. 窗口界面校验：右侧垂直区域自动渲染所有启用插件的UI面板；
5. 功能回调校验：
	- 点击左侧OBJ文件加载模型，自动执行插件on\_model\_loaded逻辑；
	- 拖拽窗口缩放，纹理缩略图自动重绘（触发on\_window\_resize）；
6. 关闭窗口：自动执行所有插件on\_destroy资源释放。

## 插件架构核心约束

1. 插件不能直接修改core/viewer\_3d\.py代码，所有扩展逻辑隔离在plugins文件夹；
2. 每个插件必须独立导入自身使用的Qt/VTK控件，不能复用内核导入；
3. plugin\_cls\_name全局唯一，YAML配置必须与插件类定义完全一致；
4. 插件UI面板统一由内核挂载至右侧容器，插件内禁止新建顶层窗口；
5. 所有模型、渲染器、日志输出统一通过self\.ctx访问，禁止插件全局变量存储模型数据；
6. 插件文件名不能以base\_开头，自动扫描逻辑会跳过该类文件。
