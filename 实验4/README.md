# 实验四 光线追踪与凹凸映射

## 编程任务1

使用 GLSL 3.30 片元着色器实现光线追踪。场景参考指导书的室内示例，包含红绿墙面、棋盘地面、矩形面光源，以及镜面球、玻璃球、木纹立方体、蓝色封闭圆柱和金属小球。支持调整物体的位置、颜色、镜面反射比例、透明透射比例、折射率和高光指数，也可修改光源及追踪参数。

双击 `run_task1.cmd` 即可运行；或在仓库根目录执行：

```powershell
.venv\Scripts\python.exe 实验4\task1_raytracing.py
```

启动脚本优先使用仓库的 `.venv`，找不到时使用 PATH 中的 `python`。缺少依赖时执行：

```powershell
.venv\Scripts\python.exe -m pip install -r 实验4\requirements.txt
```

需要显卡及驱动支持桌面 OpenGL 3.3。程序启动时会在终端打印 OpenGL 版本和显卡名称；着色器编译或渲染失败时输出错误日志，并在右侧显示错误。

## 操作

右侧面板可以滚动，下方的“物体与材质”用于选择和修改具体物体。数值框输入后按 Enter 或移开焦点即可应用。程序持续实时渲染，每帧重新计算完整场景；改变场景、相机或参数会直接作用于下一帧。

窗口底部状态栏显示实时 FPS 和平均帧间隔，按最近约一秒实际完成显示的帧统计。静止场景也持续执行光追，没有样本数量上限或收敛后停画的逻辑。FPS 包含光追、显示与窗口调度开销，实际性能由显卡、分辨率、软阴影质量和弹射深度共同决定。

| 操作 | 作用 |
| --- | --- |
| 在画面中按住左键拖动 | 围绕场景旋转相机 |
| 滚轮或按住右键上下拖动 | 拉近、拉远相机 |
| 点击画面后按空格或 Home | 重置视角 |
| 右侧“编辑物体” | 选择球、木箱、圆柱、地面或墙面 |
| 位置 X/Y/Z | 移动物体或光源 |
| 材质颜色、颜色纹理 | 修改基础颜色，选择纯色、棋盘或木纹 |
| 镜面反射比例、透明透射比例 | 修改反射、透明与局部光照的占比 |
| 折射率、高光指数 | 修改透明物体的折射程度、高光范围 |
| 重置全部 | 恢复默认场景、相机、追踪参数和画质 |
| 单帧软阴影质量 | 控制当前帧内面光源的计算次数；数值越大开销越高 |
| 保存渲染图 | 立即保存当前完整帧为 PNG |

物体可以在面板中自由移动。为便于观察正确的玻璃效果，请保持透明物体彼此分离，避免与其他物体或墙面穿插。相机也应保持在透明物体外部。

## 建议观察步骤

1. 观察默认画面。镜面球映出彩色墙壁、地板和其他物体；玻璃球呈现后方物体的变形，并保留边缘的 Fresnel 反射；木箱、球和圆柱在地面留下阴影。
2. 关闭“镜面反射”，对比镜面球与地板。该开关控制普通材质的镜面分量，玻璃界面的 Fresnel 反射和全反射仍由折射模型处理。关闭“玻璃折射”后，玻璃按当前颜色作为不透明材质参与局部光照与阴影计算。
3. 选择玻璃球，把折射率从 1.50 改为 1.00、2.00，比较后方图案的变形。折射率为 1.00 时，空气与玻璃的方向变化及界面 Fresnel 反射消失，但设定的颜色吸收与透射损失仍保留。
4. 将最大弹射深度改为 0、1、2、5。0 只计算主射线的局部照明；玻璃通常至少需要两次弹射才能穿过前后表面看到背景。较小深度会丢弃尚未追踪的反射、透射能量，镜面和玻璃区域可能变暗。
5. 关闭“软阴影”观察硬阴影，再打开并增加面光源边长，观察半影变宽。关闭“阴影遮挡”可单独比较遮挡贡献。
6. 修改木箱或圆柱的位置、反射比例、颜色，观察直接外观、影子，以及镜面球内倒影的同步变化；移动光源，观察高光和阴影位置变化。
7. 调整“单帧软阴影质量”，比较半影细节和 FPS；增大该值会增加每帧的阴影射线数量。降低内部渲染比例或弹射深度可以提高帧率，内部比例设为 1.00 可提高空间细节。默认软阴影质量为 4、内部比例为 0.75。

## 实现结构

| 文件 | 功能 |
| --- | --- |
| `task1_raytracing.py` | PyQt5 窗口、场景数据、参数面板、相机、浮点缓冲与图像保存 |
| `shaders/fullscreen.vert` | 生成覆盖窗口的三角形 |
| `shaders/raytrace.frag` | 每帧独立的主射线生成、解析求交、局部照明、阴影、反射与折射 |
| `shaders/display.frag` | HDR 曝光、色调映射和 sRGB 编码 |
| `run_task1.cmd` | Windows 启动入口 |

每个像素根据相机生成主射线，与球、轴对齐盒及封闭圆柱逐一求交，并取最近的正交点。盒体采用 slab 求交；圆柱同时计算侧面与上下端盖；从物体内部出发时选择出射交点。

交点处计算环境光近似、Lambert 漫反射与 Blinn–Phong 高光，并向面光源发射阴影射线。镜面方向使用反射定律，透明方向使用 Snell 折射与 Schlick Fresnel 近似；全反射时把该界面的透射能量转给反射。透明物体内部按传播距离做 Beer–Lambert 颜色吸收。沿法线偏移射线起点，减少自相交伪影。

GLSL 不支持递归，因此使用显式的深度优先射线栈，分别追踪反射和折射支路。最大深度为 6，栈容量为 16，单个主射线最多处理 128 个节点，并对贡献很小的支路提前终止。

每帧从像素中心生成主射线，在当前帧中完成所有反射、折射与照明计算。软阴影使用固定的低差异点列在面光源上取点，当前帧内求平均，不读取历史颜色，也不使用随时间变化的随机抖动。单个 RGBA16F 缓冲保存本帧的线性 HDR 结果，显示着色器负责曝光和颜色转换。窗口以约 16 ms 的间隔请求新帧，实际帧率取决于计算耗时与显示同步；主射线不做时间抗锯齿，物体边缘的平滑程度受内部渲染分辨率影响。

这是教学用的 Whitted 风格光线追踪，包含直接光照及镜面、折射的多次弹射。环境亮度使用常量近似；透明阴影使用沿直线穿透并衰减的近似；未计算漫反射间接照明、聚焦焦散或嵌套介质。木纹和棋盘由颜色函数生成，无需额外纹理文件。

## 截图和验证

绘制实时帧后保存渲染图及带参数面板的窗口截图，并自动退出：

```powershell
.venv\Scripts\python.exe 实验4\task1_raytracing.py --screenshot 实验4\.verification\raytracing.png
```

窗口截图自动加 `_window` 后缀。默认窗口为 1340×880，可使用 `--size 1120x760` 调整，`--render-scale 0.5` 降低内部分辨率，`--shadow-samples 1` 降低单帧阴影开销。截图的实际像素尺寸受 Windows 显示缩放影响。

执行真实 GPU 渲染检查：

```powershell
.venv\Scripts\python.exe 实验4\task1_raytracing.py --self-test --size 1000x700
```

检查基准图像不是空白、静止场景超过 64 帧仍持续执行光追且 FPS 有效、相同场景的独立帧稳定一致，并逐项修改反射、折射、阴影、弹射深度、材质颜色、物体位置和光源亮度，验证输出图像立即发生变化。全部通过会打印 `All GPU rendering checks passed.` 并以状态码 0 退出；失败时输出原因并以状态码 1 退出。检查需要可创建 OpenGL 上下文的桌面环境。

## 编程任务2 凹凸映射

任务2使用 GLSL 顶点与片元着色器实现基于高度图的凹凸映射。默认模型是程序生成的花瓶，包含外壁、内壁、底面和瓶口，区别于指导书示例的圆环；也可切换为球体。模型随源代码生成，无需下载模型或纹理。

双击 `run_task2.cmd`，或在仓库根目录运行：

```powershell
.venv\Scripts\python.exe 实验4\task2_bump_mapping.py
```

与任务1使用相同的 Python 环境和 OpenGL 3.3 要求，依赖统一放在本目录的 `requirements.txt`。任务2额外使用 NumPy 生成网格和高度数据。

### 对照与操作

默认左右并排显示同一个模型：左侧始终使用原始法线，右侧根据高度图扰动法线。两边共享相机、光源、材质、网格和纹理坐标；默认关闭“附加高度颜色”，便于单独观察凹凸造成的光照差异。右侧控制面板可滚动。

| 控件或操作 | 作用 |
| --- | --- |
| 左键拖动 / 滚轮 / 右键上下拖动 | 旋转相机 / 缩放 / 缩放 |
| 点击画面后按空格或 Home | 恢复默认相机 |
| 三维模型 | 在花瓶和球体之间切换 |
| 内置高度图 | 雕刻花纹、错缝砖纹、流动波纹、细密颗粒 |
| 加载自定义高度图 | 将图片转为灰度高度数据；明亮表示高、暗色表示低 |
| 凹凸强度 | 默认 0.100；0 恢复原始法线；负值反转凹凸方向 |
| U/V 方向重复 | 调整纹理密度，UV 变化对应的高度导数同步更新 |
| 开启凹凸映射 | 控制右侧或单视图中的法线扰动 |
| 左右并排对照 | 关闭后使用完整画面显示当前效果 |
| 显示模式 | 正常光照、法线可视化、高度图可视化 |
| 附加高度颜色 | 把高度额外用于材质明暗变化，独立于凹凸映射 |
| 材质与光源 | 调整颜色、高光、光源 XYZ 与亮度 |
| 保存渲染图 / 重置全部 | 保存当前视图 / 恢复默认场景与参数 |

建议先保持“附加高度颜色”关闭，移动光源，观察右侧高光和明暗随花纹变化。将强度设为 0 或关闭凹凸映射，两侧应完全一致；再把强度改为负值，观察高低方向反转。切到法线可视化，可以直接看到扰动后的 RGB 法线编码；高度图可视化则显示采样的高度数据，两侧应相同。

导入的图片按灰度读取，不会把普通 RGB 法线贴图解码成法线。自定义图片最好四边可平铺；超出 4096×4096 时会等比缩小。内置高度图使用浮点生成与上传，避免低精度量化被求导放大。

### 着色器实现

`task2_bump_mapping.py` 负责模型网格、UV、参数切向导数、线性高度纹理上传以及交互。花瓶外壁和内壁使用旋转曲面参数化；底面和瓶口使用平面 UV，避免将整张贴图压缩到薄瓶口。`shaders/bump.vert` 把位置、法线、UV 和表面切向导数传给片元着色器。

`shaders/bump.frag` 用中心差分从高度纹理计算 U/V 方向的高度导数，并根据纹理重复次数应用链式法则。随后把切向基投影到法平面，求解表面的度量矩阵，将 UV 高度导数转换成表面梯度。最终使用 `normalize(N - strength * gradient)` 得到扰动法线，再计算漫反射和 Blinn–Phong 高光。UV 退化的球体极点会跳过扰动，避免除零。

凹凸映射只改变光照法线，模型顶点、轮廓和深度保持不变。它不产生真实几何位移、视差遮挡或花纹自阴影。正负强度比较的是小幅位移近似下的法线变化；强度过大时会出现不自然的明暗，可以减小强度或纹理重复次数。
