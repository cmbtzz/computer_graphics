# 场景导入与 Transform 插件

在仓库根目录启动查看器：

```powershell
.venv\Scripts\python.exe 3d_viewer_framework\main.py
```

点击右侧“模型查看”选项卡，从左侧文件树或 Windows 文件资源管理器，把一个或多个 OBJ 文件拖到中间的三维画面里。左侧文件树支持 Ctrl/Shift 多选。模型会追加到现有场景；再次拖入同一个文件，会创建另一个独立实例。新模型默认排在已有模型右侧，保留源模型尺寸，导入后相机会显示整个场景。不读取 OBJ 对应的 MTL 材质文件，仍可通过原有纹理和光照插件设置外观。

左键单击模型选中它，橙色线框标记当前选择；单击空白取消选择。左键拖动不会旋转、平移或缩放相机。切换选择不会重置视角，也不会把上一物体的变换、贴图和光照参数覆盖到新选择上。

场景相机采用 Unity 风格操作（先把鼠标放在场景中操作）：

| 操作 | 功能 |
| --- | --- |
| F | 将选中物体居中并按其大小拉近取景，保持观察方向 |
| 按住右键移动鼠标 | 在相机当前位置转动观察方向 |
| 右键 + W/S | 沿当前观察方向前进 / 后退，包含俯仰方向 |
| 右键 + A/D | 向相机左 / 右方向移动 |
| 右键 + Shift + WASD | 加速移动 |
| 松开右键 / 视口失去焦点 | 立即停止自由移动 |
| 滚轮 | 前后移动；右键按住时改为调节飞行速度 |

右上角 XYZ 指示器仅显示方向。原 VTK 的左键旋转、右键缩放，以及 W/S 切换线框/面片、F 默认飞向、R 重置等场景快捷键已移除；显示模式仍可通过工具栏切换。数值框获得焦点时，字母输入不触发场景相机操作。

右侧滚动面板顶部的 **Transform** 是独立插件，包含三组 X/Y/Z 数值：

| 字段 | 含义 |
| --- | --- |
| 位置 | 模型原点的世界坐标；拖入时自动排布产生的位置也显示在这里 |
| 旋转° | 围绕源模型原点旋转，单位为度 |
| 缩放 | 各轴的缩放倍数，默认 1；负值产生镜像，0 会压平对应轴 |

输入数值后按回车或移开焦点生效，也可以点击数值框的小箭头调整。每个实例独立保存变换；“重置 Transform”仅把当前物体恢复为位置 0、旋转 0、缩放 1。重置多个模型可能让它们重叠，可再次修改位置分开。没有选中物体时，面板禁用。场景中没有新增移动、旋转或缩放手柄。

左侧文件树单击仅选择条目，便于多选和拖拽；双击文件进入单模型浏览，会替换当前场景。需要追加多个模型时使用拖拽。空文件、损坏文件和非 OBJ 文件不会清空已有模型。当前场景与变换保存在本次运行内，关闭程序后不保留。

插件标识为 `transform_control`，在 `plugin_config.yaml` 中启用。数值面板位于 `plugins/plugin_transform.py`；多物体注册、拖拽与场景拾取是查看器内核能力。插件可以通过 `on_selection_changed(obj_path, actor, polydata)` 同步当前选择，取消选择时三个参数均为 `None`。

运行集成检查：

```powershell
.venv\Scripts\python.exe 3d_viewer_framework\tests\test_scene_transform.py
.venv\Scripts\python.exe 3d_viewer_framework\tests\test_scene_navigation.py
```
