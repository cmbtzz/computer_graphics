# 光线追踪

“光线追踪”与“模型查看”并列为右侧独立选项卡，选中后直接在主窗口中心实时渲染当前 OBJ 场景。它与模型查看共用物体、Transform、材质、灯光及相机，支持凹凸映射与多个模型。独立实验程序仍在 `实验4` 目录。

## 启动与入口

启动已有的 `main.py`，右侧依次为“实验1”“模型查看”“光线追踪”。点击“光线追踪”时，中心切换为实时光追视口，右侧显示光追参数；切回“模型查看”恢复原有 VTK 视口和设置。顶部同名菜单也可切换到该页签。插件在 `plugin_config.yaml` 中的标识为 `ray_tracing`。

也可双击 `实验4/run_advanced.cmd`，直接进入光线追踪页签。依赖统一安装：

```powershell
.venv\Scripts\python.exe -m pip install -r 3d_viewer_framework\requirements.txt
```

需要支持桌面 OpenGL 3.3 的显卡和驱动。

## 建议操作流程

1. 在文件树双击 OBJ，或拖入一个或多个模型。用现有 Transform 调整朝向；例如 ModelNet 瓶子通常是 Z-up，可将 X 旋转设为 -90° 转成 Y-up。
2. 点击“一键创建 / 更新演示场景”。插件按全部导入模型的包围盒布置棋盘地面、浅色后墙、暖色侧墙、蓝色参照箱、金属球和面光源。地面略低于模型最低点，导入模型的位置、旋转和缩放保持不变。重复点击会更新布景，不会叠加副本。
3. 选中导入模型，选择陶瓷、金属、镜面或玻璃预设。基础颜色、高光等设置与原有材质面板共用；反射、透射和折射率则保存在每个物体自己的光学设置中。
4. 勾选“启用凹凸映射”，选择内置高度图或导入灰度图片，调整强度及 U/V 重复。查看器会立即显示扰动法线的光照效果。强度是物体包围盒最长边的比例，默认 0.02；负值反转凹凸，0 表示不扰动法线。
5. 在“光线追踪”页签的中心直接观察阴影、反射、折射和凹凸效果。右侧可独立开关这些效果，并调整最大弹射深度、单帧阴影质量、内部渲染比例和环境亮度。
6. 中心窗口支持左键选择物体、右键观察、右键 + WASD 飞行、Shift 加速、滚轮移动和 F 聚焦。也可以切回“模型查看”修改 Transform、普通材质、纹理或灯光；回到光追时自动使用最新设置。拖入 OBJ 同样会自动更新场景。
7. 点击“保存中心渲染图”立即保存当前完整帧。静止时仍持续执行光追，每帧独立出图，无需等待收敛。“移除演示布景”保留导入模型和其材质，恢复创建布景前的普通背景。

玻璃效果在中心光追视口中观察；模型查看页签仍以实体模型方便编辑。灯光位置、颜色及亮度使用已有的“光照设置”面板，面光源标记跟随该灯光的位置。创建布景时会配置白色灯光和观察相机。

## 可观察的现象

| 设置 | 观察内容 |
| --- | --- |
| 陶瓷 + 凹凸映射 | 高度图使高光、明暗随花纹变化；外轮廓保持不变 |
| 镜面 + 凹凸开关 | 地面与参照物出现在模型倒影中，花纹改变反射方向 |
| 玻璃 + 折射率 1.0 / 1.5 / 2.0 | 后方的棋盘和参照物发生不同程度的折射变形 |
| 阴影开关 | 地面和墙面的遮挡差异 |
| 调整灯光位置 | 模型高光和地面阴影同步移动 |
| 深度 0 / 2 / 5 | 镜面与玻璃需要后续弹射；截断时能量可能丢失而变暗 |
| 单帧阴影质量 1 / 4 / 8 | 当前帧内计算面光源的不同固定位置；数值越大半影越细，计算越多 |

环境亮度可调。未启用全景图时，未命中的射线使用渐变天空；已有“环境映射”插件启用全景背景或反射后，光追未命中射线使用同一张全景图。天空提供背景和镜面/透射参照；漫反射照明仍由显式灯光和常量环境项计算。

原有“环境映射”插件的镜面模式与同一物体的 VTK 凹凸显示互斥：全景镜面开启期间暂停该物体的 VTK 凹凸着色，关闭后恢复。中心光追视口中的环境与凹凸可以同时生效。

## 实现与范围

`plugins/plugin_raytracing.py` 实现面板、布景及 VTK 凹凸着色。模型没有 UV 时，生成柱面坐标并拆开经度接缝；有作者 UV 时保留原坐标。原有颜色纹理可继续使用。

`core/lab4_scene.py` 对几何、Transform、材质和纹理变化自动同步，三角化后应用完整世界矩阵。法线采用逆转置变换。全场景统一归一化，再以最长质心轴中位数构建 BVH；三角形、节点和材质通过 OpenGL 3.3 纹理缓冲上传。静态场景复用这些数据，相机与灯光逐帧更新，移动相机不会重建 BVH。

`core/lab4_preview.py` 中的 `MeshTraceView` 已作为中心视口嵌入主窗口。它与 `shaders/lab4/mesh_trace.frag` 完成 GPU BVH 遍历、双面三角形求交、重心插值、局部照明、面光源阴影、Fresnel 反射/折射和颜色吸收。高度图通过中心差分和 UV 度量转换为表面梯度，扰动后的法线参与直接光照、反射和折射；射线起点偏移使用几何法线。每帧独立完成计算，不读取历史颜色；单个 RGBA16F 缓冲保存本帧 HDR 颜色，最后做色调映射与显示编码。

这是 Whitted 风格教学渲染器。支持普通透视相机和正交相机、最多 128 个物体和 100 万个三角形，实际容量还受显卡纹理缓冲限制。内部渲染最高 1152×864，默认渲染比例为 0.5、单帧阴影质量为 1。FPS 在右侧持续更新，性能取决于模型复杂度、画质和显卡；保存时输出中心视口大小的图像。隐藏光追页签后停止计算。

玻璃适合封闭、法线向外、互不嵌套的网格，相机应位于透明物体外部。透明阴影沿直线穿透并衰减；未模拟焦散、漫反射全局光照、嵌套介质、几何位移或花纹自阴影。高度图按灰度数据解释，不解码 RGB 法线贴图。曲面极点或退化 UV 会跳过无法求解的法线扰动。

## 演示与验证命令

```powershell
# 内置示例瓶子自动转为 Y-up，再布置场景；默认陶瓷与凹凸映射
.venv\Scripts\python.exe 实验4\advanced_viewer.py --demo

# 自己的模型保持原始 Transform；创建场景并使用镜面预设
.venv\Scripts\python.exe 实验4\advanced_viewer.py --model D:\models\bottle.obj --demo --preset 镜面

# 保存中心实时光追图及加 _window 后缀的主窗口截图并退出
.venv\Scripts\python.exe 实验4\advanced_viewer.py --demo --preset 镜面 --screenshot 实验4\.verification\advanced_demo.png

# CPU BVH 对照、真实 VTK/GPU 渲染和场景同步检查
.venv\Scripts\python.exe 实验4\advanced_viewer.py --self-test

# 同级页签、中心视口、持续刷新、导航和自动同步验证
.venv\Scripts\python.exe 3d_viewer_framework\tests\test_lab4_live_view.py
```
