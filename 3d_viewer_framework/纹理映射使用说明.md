# 模型查看中的纹理映射

在仓库根目录运行：

```powershell
.venv\Scripts\python.exe 3d_viewer_framework\main.py
```

若使用新 Python 环境，先安装 `3d_viewer_framework/requirements.txt` 中的依赖。

点击右上角的“模型查看”。右侧所有设置自上而下排列在同一个滚动面板中；点击分组标题可展开或收起，内容过长时向下滚动。

模型视口右上角的 XYZ 指示器随相机方向旋转，缩放或平移时保持固定的屏幕大小。它只显示方向，不拦截鼠标操作，也不参与模型取景。

场景采用 **+Y 向上**，输入统一为 Unity 风格：左键选择物体，F 聚焦选中物体；按住右键移动鼠标原地转向，右键 + WASD 自由移动，Shift 加速。松开右键或视口失去焦点立即停止移动。原先的左键旋转、右键缩放和 VTK 默认 W/S/F/R 等快捷键已移除。详细操作见 [场景与 Transform 使用说明](场景与Transform使用说明.md)。

模型本体上也保留局部 XYZ 坐标轴，锚点位于模型中心，方向跟随模型的变换。轴长根据相机和锚点深度实时换算，约为 76 个屏幕像素，不再使用固定的 15 个模型单位；轴线与箭头统一缩放，保持清晰粗细。XYZ 字母每帧根据轴端投影定位，与轴端保持固定屏幕间距，缩放时位置和字号保持稳定。

1. **普通纹理**：在左侧选择 OBJ 模型，再点击纹理缩略图，将贴图应用到当前模型。
2. **Mipmap 设置**：为普通贴图选择六种 OpenGL 过滤方式。滚轮拉远模型，比较远处纹理的走样与闪烁。此处不修改环境反射的采样设置。
3. **环境映射**：勾选“启用模型镜面反射”，将当前模型切换成反射全景环境的材质；勾选“显示全景背景”可显示同一环境。两个开关可以独立使用。
4. **光照设置**：调节原有的环境光、漫反射和镜面高光。控件也纵向排列。

环境映射默认读取 `实验2/meadow_2_4k.exr`。可点击“选择 EXR 全景图…”更换图片。背景和反射使用同一张全景图，EXR 统一做色调映射后用于显示。镜面反射直接采样原始全景纹理的第 0 层，保留细节，不再经过粗糙表面的立方体贴图预过滤。它属于静态环境反射，模型不会反射场景中的其他模型。

环境以 **+Y 为天空、XZ 为地面**，背景和反射采用相同的方向映射。背景为无限远全景，仅随相机朝向旋转，不受相机平移、拉近拉远或正交缩放影响。开启背景时视野扩大为 60°，同时调整相机距离，尽量保持模型的屏幕大小；关闭背景会恢复原来的视野。

关闭镜面反射会恢复当前模型原来的贴图与材质；直接选择普通纹理也会关闭反射。切换 OBJ 模型后，纹理、过滤选项和环境开关继续应用到新模型。

代码仍以 `Base3DPlugin` 插件方式扩展，通过 `plugin_config.yaml` 启用 `texture_mapping`、`mipmap_mapping` 和 `environment_mapping`，未修改查看器内核。`实验2` 下的两个独立演示程序保留原来的运行方式。
