# 光照与材质

在仓库根目录运行 `.venv\Scripts\python.exe 3d_viewer_framework\main.py`，切换到“模型查看”。拖入多个 OBJ 后，单击场景中的物体，右侧材质面板会显示该物体独立保存的参数。

面板顺序为 Transform、光照设置、材质设置、普通纹理、Mipmap、环境映射。标题可折叠，右侧可滚动。

## 场景灯光

光照设置中的启用光照、环境光、漫反射、镜面高光开关作用于全部模型；关闭某分量只暂停它对显示的贡献，不修改模型保存的材质值。启用光照关闭时，自发光仍然可见，全景背景的显示开关保持独立。

灯光为世界坐标中的点光源，可编辑 XYZ 位置、RGB、灯光强度和环境光强度。环境光强度单独控制物体环境反射项；RGB 和灯光强度同时影响环境项及直接照明。

先点击场景，使键盘焦点进入场景：

| 按键 | 操作 |
| --- | --- |
| 左右、上下方向键 | 移动灯光 X、Y，步长随模型尺寸调整 |
| PageUp / PageDown | 移动灯光 Z |
| R / G / B | 对应颜色分量增加 0.05 |
| Shift + R / G / B | 对应颜色分量减少 0.05 |

按住右键飞行时，键盘仍属于原相机控制。数值框编辑时，方向键仍用于编辑数值，不会移动灯光。

## 当前物体材质

OBJ 缺少有效顶点法线时，导入会自动生成平滑法线，并以 60° 特征角保留明显硬边。辅助计算合并重合坐标，最终保留原来的 UV 接缝、几何位置与面数；已有有效作者法线则保留。配合 Phong 插值，曲面高光可跨三角形连续变化。更新程序后需要重新导入模型才能应用。

材质设置包含环境光、漫反射、镜面反射、自发光的颜色与强度，以及高光指数。这里的环境光是经典光照模型中的常量照明项，不是全景图或环境映射。未选中物体时禁用编辑。修改参数后预设显示为“自定义”；切换选中物体会恢复各自的面板数值。

高光指数越大，高光越集中；亮度还受镜面强度、光源颜色、强度与位置影响。自发光只增加自身颜色，不会照亮其他物体。“重置当前物体材质”恢复默认材质，保留其普通贴图。

| 预设 | 设置与操作 |
| --- | --- |
| 默认 | 中性灰色、一般高光 |
| 金属 | 亮银灰色、同色系暗部、宽而明亮的冷白高光 |
| 木材 | 暖棕色、棕色暗部、很弱的反光；木纹仍在原“普通纹理”面板手动选择 |
| 塑料 | 饱和红色主体、红色暗部、清晰的白色高光 |

这些预设只使用本次实验的经典 Phong 光照与材质参数构成外观，不启用环境映射。木材预设本身不自动生成或附加木纹。材质数值保存在当前程序运行期间。

## 普通贴图与上次实验

普通贴图仍通过原面板手动选择，材质预设不切换贴图、不调用环境映射，也没有环境反射混合参数。

上次实验的环境映射插件保留原有独立功能。进行本次光照材质实验时，保持其模型镜面反射关闭，以观察经典光照与材质效果。

普通纹理插件、Mipmap 插件及相机控制未作修改。环境映射插件已恢复本次扩展前的实现。材质存储与着色适配位于 `plugins/base_material.py`；独立材质插件标识为 `material_control`，在配置文件中启用，支持不加载环境映射插件的配置。
