# 实验三 光照与材质

## 编程任务1

本程序独立运行，无需启动 3D 浏览器框架。双击 `run_task1.cmd`，或在仓库根目录运行：

```powershell
.venv\Scripts\python.exe 实验3\task1_lighting.py
```

画面排列为三行四列。三行分别为无环境光、白色环境光、有色环境光；四列分别为仅漫反射、漫反射加低高光、漫反射加强高光、漫反射加自发光。后两行在相应列的基础上增加环境反射。第一行的环境材质为零，程序同时关闭 OpenGL 默认全局环境光，避免出现额外环境光贡献。指导书第二行第一列的“而镜面反射光”按上下文理解为“而无镜面反射光”。

先点击渲染画面，再使用键盘：

| 操作 | 功能 |
| --- | --- |
| A/D 或左右键 | 灯光沿世界 X 轴移动 |
| W/S 或上下键 | 灯光沿世界 Y 轴移动 |
| Q/E | 灯光沿世界 Z 轴正/负方向移动 |
| R/G/B | 增加灯光对应 RGB 分量，每次 0.05，最大 1 |
| Shift+R/G/B | 减少对应 RGB 分量，最小 0 |
| 左键拖动 | 围绕球体阵列旋转视角 |
| 滚轮 / 右键上下拖动 | 拉近或拉远视点 |
| 空格 / Home | 重置视角 / 重置全部参数 |

默认颜色与光照参考指导书内编程任务1的示例图片：深青色背景、蓝色漫反射、第二行灰色环境反射、第三行黄绿色环境反射，第四列叠加红褐色自发光。灯光位于上方靠近观察者的一侧，第二列使用宽而柔和的高光，第三列使用集中的高光。

右侧面板可精确调整灯光位置、RGB、环境光强度，以及材质的环境反射、漫反射、镜面反射、高光指数和自发光。两个颜色选择按钮分别改变漫反射与自发光的颜色。第二行的环境材质 RGB 相等，第三行的环境材质偏黄绿；在默认白色灯光下可观察无色与有色环境反射的差别。灯光颜色改变后，环境反射也受光色影响。

建议把环境光强度调为零，观察第二、三行与第一行的差别消失；将 RGB 全部调为零，观察仅第四列仍因自发光可见。高光指数越大，高光越集中；高光亮度还受镜面反射强度影响。固定管线的自发光不照亮其他物体。

保存包含参数面板的窗口截图后退出：

```powershell
.venv\Scripts\python.exe 实验3\task1_lighting.py --screenshot 实验3\.verification\lighting_task1.png
```

依赖见本目录 `requirements.txt`，可使用仓库已有的 `.venv`。缺少依赖时执行 `.venv\Scripts\python.exe -m pip install -r 实验3\requirements.txt`。使用桌面 OpenGL 2.1 固定管线兼容上下文。
